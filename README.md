# IconNormalizer: Автоматичне центрування та масштабування іконок

## 📌 Загальний опис проєкту (Overview)

**IconNormalizer** — це консольна утиліта на базі Python для пакетної передобробки та стандартизації графічних іконок формату PNG з прозорим фоном. Проєкт вирішує проблему хаотичного розміщення елементів та різного масштабу іконок усередині фіксованих цифрових полотен.

## 🎯 Цілі проєкту (Project Goals)

- **Автоматизація рутини:** Виключити ручну роботу в графічних редакторах (Photoshop/Figma) для вирівнювання великої кількості графічних елементів.
- **Уніфікація контенту:** Привести всі вхідні зображення до єдиного стандарту розміру та візуального балансу.
- **Оптимізація для UI/UX або ML:** Підготувати іконки для коректного відображення в інтерфейсах (мобільні додатки, вебсайти) або для використання як датасет у задачах комп'ютерного зору (Computer Vision).

## 👥 Суб'єкт та об'єкт проєкту (Subject & Object)

**Об'єкт дослідження/обробки:** Растрові графічні файли (іконки, логотипи, гліфи) у форматі PNG (RGBA) з роздільною здатністю 200x200 пікселів, що мають надлишкові або нерівномірні прозорі поля навколо корисного вмісту.

**Суб'єкт (Користувач проєкту):** UI/UX дизайнери, веб-розробники, розробники мобільних додатків або дата-саєнтисти (Data Scientists), яким потрібен ідеально відцентрований та масштабований графічний контент.

## 🛠 Технічний стек (Tech Stack)

- **Мова програмування:** Python 3
- **Основна бібліотека:** Pillow (PIL) — для аналізу альфа-каналу (прозорості), кадрування, геометричного масштабування та композиції зображень.

## ⚙️ Етапи роботи алгоритму (Workflow)

1. **Зчитування даних:** Потокове сканування вхідної папки з файлами.
2. **Аналіз прозорості (Bounding Box):** Визначення точних координат (bbox) крайніх видимих (непрозорих) пікселів ігноруючи пустий простір.
3. **Обрізання (Cropping):** Видалення «зайвих» прозорих полів навколо іконки.
4. **Пропорційне масштабування (Rescaling):** Зміна розміру обрізаного об'єкта під цільовий стандарт (наприклад, об'єкт займає рівно 85% від фінального полотна).
5. **Центрування (Centering):** Створення нового чистого полотна 200x200 та вставка об'єкта чітко по центру (розрахунок зміщення за формулою координат центру).
6. **Збереження:** Експорт готового файлу з пресетом високої якості згладжування (LANCZOS).

## 📊 Очікуваний результат (Expected Output)

На виході отримується папка з іконками, які:

- Мають однаковий фізичний розмір полотна (200x200 px).
- Візуально збалансовані (корисний малюнок займає однаковий відсоток площі у кожному файлі).
- Розташовані строго по центру по вертикалі та горизонталі.
